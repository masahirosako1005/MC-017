## 4. 発表で手で行うときの注意
- 先に `npm run build` のあと `npm run start:demo`（3000、DEMO_MODE=1）で起動する。VOICEVOX ENGINE を起動していれば相棒の声、無ければブラウザの声か文字だけ（どちらでも流れは同じ）。
- 手順 7 で設定を開く画面がホームでないとき、「この設定でもどる」は開く前の画面へ戻る。そのときは左上の「もどる」でホームへ。
- 1日目の状態に戻すには、設定のデモ操作「もとに戻す」か、ブラウザのサイトデータを消して新しいダミー ID で開き直す。
- デモ操作は DEMO_MODE のときだけ出る。DEMO_MODE を付けない起動（`npm start`）では出ない（AC-052）。
