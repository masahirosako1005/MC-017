# SC-03 スポット（地図・概要）（画面設計）

作成: 2026-11-09 15:06（実測） / 到達点: M3 / モック: `docs/10_企画/画面モック/SC-03_スポット.html`（1対1。見た目の正は `index.html#spots`・`#sheet`・`#list`、ADR-002）
上流: 方向性 §6「スポット」・§19.3、competition ルール（地図）、ADR-012（地図とオフライン）、要件定義 R-008〜R-011・R-045。

## 1. 目的
名古屋のスポットを季節のイベントで探す。地図（Leaflet＋地理院の淡色地図）で、ドラッグなしでも（アイコンへの Tab と Enter／Space、拡大・縮小のボタン）全部のスポットへ行ける。押すと下から 1/3 の概要が出て、詳細へ進める。

| 2.4.11 | 出典のプレート・概要シート・下のメニューに、フォーカスしたアイコンが隠れない（選んだアイコンへ地図を動かす） |
| 2.5.1 / 2.5.7 | ドラッグ・ピンチなしで、拡大縮小ボタンと、アイコンへの Tab・Enter で全スポットの概要と詳細へ行ける（一覧は削除） |
| 2.5.8 | アイコン 48px、拡大縮小 46px、季節タブ 28px（24px 以上。隣との間隔 8px）、出典のリンク 44px 以上 |

| 4.1.3 | 「オフライン表示中」の出入りを `aria-live="polite"` で知らせる |

- 使いにくくなる人と対策（INC-01）: 指の細かい動きが難しい人→ボタンとキーボード。電波が不安定な旅行者→簡易地図。地図が見づらい人→一覧が無いので、拡大ボタンとアイコンの名前（読み上げ）に頼る【仮定: 残るリスク】。
- だれのための工夫か（INC-03）: ドラッグの代わり（ボタンとキーボード）は車いすの人（P-04）のためだが、高齢者にも効く。

## 9. M4 の E2E で確かめる観点
- 淡色地図のタイル（`/xyz/pale/`）とアイコンが出る。季節タブで強調が変わる。拡大・縮小で縮尺が変わる（AC-011）。
- アイコンを押すと約 1/3 の概要、「詳細を見る」で SC-04（AC-012）。Esc で閉じる。
- 地図・簡易地図・概要のどれでも「出典：地理院タイル」が見え、リンク先と `target`・`rel` が正しい（AC-013）。
- タイルを `page.route` で失敗させると簡易地図と「オフライン表示中」、アイコンを押せる。戻すと自動で通常の地図（AC-014）。
- 一覧は無い。アイコン11個すべてに「名前、季節」の名前があり、Tab で移って Enter／Space で概要が開き、Esc で閉じる。詳細から戻ると地図と選んだ季節のまま（AC-015 の差し替え）。
- DEMO_MODE でいる場所を選ぶと「いまここ（デモ）」が出て、地図にだけ出る（AC-054）。
- 390px・430px で横スクロールなし、操作要素 44px 以上（AC-062）、キーボードで操作（AC-063）。

## 10. index.html との違い
1. 地図は自作 SVG の見本ではなく Leaflet＋地理院の淡色地図（見た目の部品・位置は index.html どおり）。
2. 「いまここ（デモ）」を足す（R-045）。index.html の一覧は削除した。
3. オフラインの簡易地図と「オフライン表示中」を足す（R-010）。
4. 出典のプレートの高さを 44px 以上にする（ux ルール）。

## 11. 【仮定】
- 出典のプレートを 44px にする。
- 概要を閉じたらアイコンへフォーカスを戻す。
- Leaflet の初期化に失敗したときは簡易地図へ。
- デモの距離は直線距離で「約 n m」（近くのお店と同じ計算）。
