### さいころと駒の動き（R-023）
1. 押すとすぐ `requestId` を作って API 10 を送り、ボタンを `aria-disabled="true"`（素早い2回押しでも1回だけ。AC-061）。同時に**盤・ヘッダー・下のメニューの上に画面いっぱいのさいころ**（`role="dialog"` `aria-modal="true"`、スマホの枠いっぱい）を出し、フォーカスを「とばす」に移す。サーバーの目が届くまではゆっくり回して待つ。
2. 目が届くと、150px の立体（CSS 3D）が**右から転がり込み、数回弾みながら約4.8秒かけてだんだん遅くなって目を止める**（床と影つき。Web Animations API、外部の CSS ファイル）。転がっている間は「こつこつ」音（効果音「なし」では鳴らさない）。
3. 止まると面が光り、「4 が出た！」「4 マス進むよ」とボタン「すすむ」。約1.2秒たつか「すすむ」で閉じ、フォーカスを「さいころを振る」へ戻す。「とばす」または Escape を押すと、転がりを切り上げて止まった面を出し、約0.2秒で閉じる（目は変わらない）。閉じたあと0.25秒おいて、**駒を画面の真ん中へ寄せ（スクロールするのは本体の `main` だけ。振る前に盤の別の場所を見ていても駒が見える）**、さらに0.35秒おいてから駒が動く。動いている間は、駒が画面の上下30%の外に出たときだけ真ん中へ寄せ直す（1マスごとには動かさない）。結果のカード（#5）が盤の上に入ったあとは、カードを読めるように自動では動かさない。
4. 駒は1マスずつ跳ねて進む（1マス約0.26秒、効果音「ぽん」）。44（ゴール）を越える目でも 44 で止まる。
5. 結果のカード（#5）と相棒のセリフ（#6）を出し、`aria-live` で「4 が出ました。11 マス目に進みました。あと 3 マスでプレゼントのマス」と知らせる（音の設定と関係なく出す）。全画面の中にも `role="status"` で「4 が出ました。4 マス進みます」を出す。
6. **動きを減らす設定**（`prefers-reduced-motion: reduce`）では、さいころは回さず約0.5秒で面を出し、約0.7秒で閉じ、駒は跳ねずに移り、紙吹雪は少なく短く。

## 9. M4 の E2E で確かめる観点
- 残り回数が出て、0回のときはボタンが無く、増やし方が出る（AC-024）。
- 盤が縦長の SVG で45マス・1段5マス・スタートが左上・ゴールが右下・特典マス9・名古屋城の絵。駒は選んだアバターの絵。開くと駒の位置へスクロールし、盤の文字が出る（AC-025）。
- 振る前に盤の下のほうを見ていて駒が画面の外にあっても、さいころが閉じたあと駒が画面の中に入り、動いている間は見え続ける（AC-068）。
- さいころが画面いっぱいで約5秒かけて止まり、止まった目で「が出た！」と進むマス数が出て、閉じると駒が進む。「とばす」・Escape で早く閉じ、動きを減らす設定では回らない（AC-068）。
- 動きを減らす設定で約0.5秒で止まり、結果が `aria-live` に出る（AC-030）。
- さいころを素早く2回押しても回数は1だけ減る（AC-061）。
- 効果音なしでは Web Audio を作らない（AC-029 の画面側）。
- 偽のエンジンで、振った後のセリフが吹き出しと同時に鳴り、右下に「VOICEVOX:話者名」（AC-050）。
- キーボードで下のメニューから「遊ぶ」→振る（AC-063）。

## 10. index.html との違い（後の指示を採る）
1. 盤は index.html の 20マス・4段ではなく、**45マス・1段5マス・9段の縦長ジグザグ**（左上=スタート・駅、右下=ゴール・名古屋城、絵の背景つき）。色・角丸・マスの色分け・カードは index.html のまま（方向性 §16.1・§19.12、ADR-002、ADR-022）。
2. さいころは index.html の平らな目の揺れではなく、**画面いっぱいの立体（CSS 3D）が約4.8秒かけて止まる**（状況のカードの小さいさいころは止まった目を見せる）。
3. 駒は index.html の仮の猫ではなく、いまのアバターの `<img>`。
4. 結果のセリフは相棒の吹き出しで、読み上げ「あり」なら**操作のあと自動で読む**（index.html は読まない）。
5. 「増えたきっかけ」に再訪・予言・デモを足す。
