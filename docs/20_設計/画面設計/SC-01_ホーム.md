# SC-01 ホーム（画面設計）

作成: 2026-11-09 15:06（実測） / 到達点: M3 / モック: `docs/10_企画/画面モック/SC-01_ホーム.html`（1対1。見た目の正は `index.html#home`、ADR-002）
上流: 方向性 §6「ホーム」・§19.2・§17.3・§18、要件定義 R-001〜R-005・R-007・R-040〜R-042、コンセプト「再訪の因果」。

## 1. 目的
旅を始める・続ける入口。**「すごろくの続き」「次はどこ？（予言）」「再訪ボーナスのあいさつ」で、前の旅の続きが手元に残っていることを最初に見せる**（再訪の因果の「次に来る理由」）。あわせて、はじめの選択（年齢・一緒に来た人・段差少なめ）とおすすめコースを出す。

## 3. 要素（上から順）
| # | 要素 | 内容・ルール | データ |
|---|------|--------------|--------|
| 1 | ヘッダー | 左にロゴの丸と h1「名古屋すごろく旅」、右に設定（歯車 48px、`aria-label="設定"`）。下のメニューのある画面なので「もどる」は無い | — |
| 2 | アバター | いまの相棒の絵を `<img>`（78px、同じオリジンの `/avatars/<id>-<表情>.svg`）。alt は「名前（表情）」例「ともにゃん（にこにこ）」。ボーナスがある日は excited（わくわく）、ほかは happy（にこにこ）。絵の下に名前と「変更」リンク（44px 以上）→ SC-02 | `MeState.profile.avatar`・`bonus` |
| 3 | あいさつの吹き出し | 初日:「ようこそ！…」、旅の2日目:「こんにちは！今日もよろしくね。さいころが1回 増えたよ。」、再訪:「また来てくれたね！再訪ボーナスで さいころが2回 増えたよ。」、それ以外:「こんにちは！今日はどこへ行こうか？」。読み上げ「あり」のとき吹き出しに「読み上げ」ボタン（読み上げ中は「止める」）。**開いただけでは読まない**（方向性 §17.3） | `visitKind`・`bonus` |
| 4 | すごろくの続き（主色のカード） | h2「すごろくの続き」、「n枚目」「n / 45 マス」、進み具合の棒（飾り）、「さいころ あと n回」、「続きを遊ぶ」（金のボタン）→ SC-05 | `board`・`rollsLeft` |
| 5 | 次はどこ？（index.html に無い。足す） | h2「次はどこ？」。予言があるとき: 小さな相棒の絵と「次は（季節）の（時間帯）、（スポット名）が気に入るはず」、ボタン「予言を見る」→ SC-09。予言がまだ無いとき（QR 0回）:「スポットで QR を読むと、相棒が予言できるようになるよ」とボタン無し。答え合わせを待つ予言は「（スポット名）で答え合わせを待っています」 | API 14 `ProphecyState.current`・`canProphesy` |
| 6 | はじめに選んでね | h2 と説明「選ぶと、うわさとおすすめが あなた向けになります。選ばなくても使えます。」。年齢（選ばない・10代〜60代以上）と一緒に来た人（選ばない・ひとり・家族・夫婦・友達）の `<select>`（`<label for>`）。**段差少なめ**のトグル（`aria-pressed`、チェックの印と文字）【仮定: R-002 に合わせてここに置く】。選ぶとすぐ保存（画面は移らない） | API 6 `PATCH /api/me/profile` |
| 7 | 今日のおすすめコース | カード（アイコン・名前・所要時間・歩く距離・段差少なめ／段差あり・休憩所の数）。**段差少なめを選ぶと段差のあるコースを出さず**、「『段差少なめ』を選んでいるので、段差のあるコースは出していません。」と書く（R-004） | マスタ `courses`（3件） |
| 8 | 注目のイベント | いまの季節のイベント1つ（季節のチップ・イベント名・スポット名・＞）。押すと SC-04 | マスタ `spots`・アプリ内の今日の季節 |
| 9 | 架空の注記 | 「スポットの内容とイベントは架空です（一部の施設は位置のみ実在）。」 | — |
| 10 | 下の操作 | 「スポットを探す」（主ボタン 58px）→ SC-03 | — |
| 11 | 下のメニュー | ホーム（`aria-current="page"`）・スポット・遊ぶ・うわさ・特典 | — |
| 12 | VOICEVOX の表示 | VOICEVOX の声で鳴っている間だけ、画面の右下（下のメニューの上）に「VOICEVOX:話者名」（例「VOICEVOX:春日部つむぎ」）。ブラウザの声では出さない | 読み上げの状態 |

- 名前・メール・LINE ID の入力欄は無い（R-001・R-057）。ダミー ID は表示しない【仮定: 見せる必要がない】。

## 4. 状態
| 状態 | 画面 | 次の行動 |
|------|------|----------|
| 読み込み中 | アプリを開いた直後、利用開始（API 4）が返るまで画面の中央に「読み込み中…」（`role="status"`）。「次はどこ？」は取得中「相棒が考えています…」 | 待つ |
| 空（初めて） | あいさつは初日の文、すごろくは「1枚目」「1 / 45 マス」「さいころ あと0回」。「次はどこ？」は「スポットで QR を読むと…」。年齢・一緒に来た人は「選ばない」 | 「スポットを探す」 |
| エラー | 開けない:「サーバーにつながりません。アプリを起動しているか確かめてね。」と「もう一度」。保存の失敗:「うまくいきませんでした。少し待ってから もう一度ためしてね。」と「もう一度」「閉じる」（`role="alert"`） | もう一度 |
| オフライン | サーバーは同じ PC（127.0.0.1）なので、ネットが切れてもこの画面はそのまま使える。**地図が無いので「オフライン表示中」は出さない** | そのまま使う |
| 再訪・旅の2日目 | あいさつがボーナスの文、相棒は excited。さいころの回数が増えている | 「続きを遊ぶ」 |
| 段差少なめ | コースから段差ありが消え、注記が出る | — |
| 読み上げ中 | 相棒が表情と talk の絵を約0.15秒で交互（動きを減らす設定では talk のまま）。ボタンは「止める」 | 止める |

## 8. アクセシビリティ（WCAG 2.2 AA）
| 達成基準 | 確認の観点 |
|----------|------------|
| 1.1.1 | アバターの `<img>` の alt が「名前（表情）」。ロゴ・アイコンは `aria-hidden` |
| 1.3.1 / 2.4.6 | h1（アプリ名）→ h2（すごろくの続き・次はどこ？・はじめに選んでね・おすすめコース・注目のイベント）。`<select>` に `<label for>` |
| 1.4.1 | 段差少なめはチェックの印と文字、コースの段差は「段差少なめ／段差あり」の文字 |
| 1.4.3 / 1.4.11 | 主色カードの白文字（#FFFFFF／#0E7C74）と金ボタンの文字（#3B2A00／#F4B43A）を M4 で計算（C） |
| 1.4.4 / 1.4.10 | 文字「大」・幅 320〜430px で横スクロールが無い（AC-044・AC-062） |
| 2.2.2 | 口パクは読み上げ中だけ。動きを減らす設定では交互にしない |
| 2.4.11 | 下の操作ボタンと下のメニューに、フォーカスした要素が隠れない（`scroll-padding-bottom`） |
| 2.5.3 | 「変更」「続きを遊ぶ」の見える文字が名前に含まれる |
| 2.5.8 | 操作要素 44px 以上（select 52px・ボタン 58px） |
| 3.2.2 | 年齢などを選んでも画面は移らない（保存だけ） |
| 4.1.2 | 段差少なめのトグルは `aria-pressed` |
| 4.1.3 | 保存の失敗は `role="alert"`、読み込み中は `role="status"` |
| 1.4.2 | 読み上げは押したときだけ、「止める」がある |

- 使いにくくなる人と対策（INC-01）: 文字が読みにくい人→文字の大きさと読み上げ。段差が苦手な人→段差少なめでコースを絞る。日本語が読めない人→English。
- だれのための工夫か（INC-03）: 段差少なめは車いすの人（P-04）のためだが、ベビーカーの家族（P-01）や高齢者（P-03）にも効く。

## 9. M4 の E2E で確かめる観点
- 初めて開くとダミー ID が作られ、名前・メールの入力欄が無い。再読み込みで同じ ID（AC-001）。
- アバターの絵（alt「ともにゃん（にこにこ）」）・名前・「変更」・あいさつ・すごろくの続き（何枚目・何マス目・残り回数）・「次はどこ？」・注目のイベント・架空の注記が出る（AC-004・AC-009）。
- 段差少なめを押すと段差ありのコースが消える（AC-005 の画面側）。
- デモで＋1日→あいさつが「旅の2日目」、＋7日→「再訪」（AC-006 の画面側、AC-053）。
- 「読み上げ」で口パクが交互になり、終わると戻る（AC-010）。VOICEVOX の偽エンジンで鳴らすと右下に「VOICEVOX:春日部つむぎ」（AC-050）。
- API を止めると原因と「もう一度」が出る（AC-064）。

## 10. index.html との違い（後の指示を採る）
1. 「変更」は SC-02 へ移る（index.html は「省略しています」のお知らせ）。
2. 「次はどこ？」を足す（R-003・方向性 §15）。
3. アバターは仮の猫の絵ではなく `<img>`（§18）。
4. 段差少なめのトグルを「はじめに選んでね」に足し、段差のあるコースを出さない（R-002・R-004）。
5. 読み上げは「押したときだけ」はホームでも同じ（開いただけでは読まない）。

## 11. 【仮定】
- 「次はどこ？」の位置はすごろくの続きのすぐ下。
- 段差少なめのトグルは「はじめに選んでね」の中。
- ダミー ID は画面に出さない。
