# SC-08 友達を誘う（LINE 見本）（画面設計）

作成: 2026-11-09 15:06（実測） / 到達点: M3 / モック: `docs/10_企画/画面モック/SC-08_友達を誘う.html`（1対1。見た目の正は `index.html#invite`。相棒の吹き出しの `<img>` の見本を足した）
上流: 方向性 §6・§8（LINE はモック）・§19.7、要件定義 R-015。

## 1. 目的
友達に「今度ここに一緒に行こうね！」と誘う**見本**（実際には送らない）。誘った約束が、次に友達と来るきっかけになる。送ると、このスポットで1日1回さいころが増える。

## 2. 対応
| 種類 | 番号 |
|------|------|
| 要件 | R-015（LINE の見本・送らない・＋1）、R-050（外部へ送らない）、R-053（二重送信）、R-057（LINE ID を扱わない）、R-007（相棒の絵）、R-055 |
| ストーリー | US-004 |
| 受け入れ基準 | AC-021（画面側）、AC-056（外へ送らない）、AC-060（画面側） |

## 3. 要素（上から順）
| # | 要素 | 内容・ルール | データ |
|---|------|--------------|--------|
| 1 | ヘッダー | 左に「もどる」、h1「友達を誘う」、右に設定 | — |
| 2 | 説明 | 「友達に『今度一緒に行こう』と送ろう」 | — |
| 3 | 会話の見本 | 上の帯: 丸いアイコン・「友達」・灰色のチップ「LINE（見本）」。会話: 主色の吹き出し「今度ここに一緒に行こうね！」と、その中のスポットのカード（アイコン・スポット名・イベント名）。下に「まだ送っていません」 | `spotId`・マスタ |
| 4 | 見本の注記 | 金色の帯「見本です。実際には送信されません。」 | — |
| 5 | 相棒の吹き出し | 相棒の `<img>`（60px、alt「名前（にこにこ）」）と「友達と来ると、すごろくの続きも いっしょに遊べるよ」。読み上げ「あり」なら「読み上げ」ボタン（開いただけでは読まない） | `avatar` |
| 6 | 下の操作 | 「送信（見本）＋1」（主ボタン）。今日このスポットで済みなら「＋1」の印を出さない | `doneToday` |

- 友達の名前・LINE ID・電話番号の入力欄は無い。宛先も選ばない（R-057）。
- 下のメニューは出さない（サブ画面）。

## 4. 状態
| 状態 | 画面 | 次の行動 |
|------|------|----------|
| 読み込み中 | 内容はマスタなので即座に出る。送信中はボタンが押せない | 待つ |
| 空 | 該当なし（スポットが必ずある）。スポットが無いときは SC-04 の「見つかりませんでした」と同じ | もどる |
| エラー | 「サーバーにつながりません…」か「うまくいきませんでした…」と「もう一度」 | もう一度 |
| オフライン | 外へは送らない画面なので、ネットが切れても同じに動く。**地図が無いので「オフライン表示中」は出さない** | そのまま使う |
| 送った | 「誘いました（見本）。さいころ＋1」のお知らせを出して SC-05 へ。今日すでに誘っていたら「誘いました（見本）」だけ（回数は増えない） | SC-05 |

## 8. アクセシビリティ（WCAG 2.2 AA）
| 達成基準 | 確認の観点 |
|----------|------------|
| 1.1.1 | 相棒の alt、会話のアイコンは `aria-hidden` |
| 1.3.1 | 会話の見本は見出しの代わりに「友達」の帯。注記は段落 |
| 1.4.3 | 主色の吹き出しの白文字（#FFFFFF／#0E7C74）を M4 で計算 |
| 2.5.3 | ボタンの名前に「送信（見本）」を含む |
| 2.5.8 | ボタン 58px |
| 3.3.4 | 送っても外へは出ない見本であることを、押す前に注記で書く |
| 4.1.3 | 送った後のお知らせを `role="status"` で |

- 使いにくくなる人と対策（INC-01）: 本当に送られるのが不安な人→「見本です。実際には送信されません」を目立つ帯で。
- だれのための工夫か（INC-03）: 見本の注記は誤送信が怖い人のためだが、子ども（P-06）にも安心。

## 9. M4 の E2E で確かめる観点
- 「見本です。実際には送信されません」が出て、送ると SC-05 でさいころ ＋1（AC-021 の画面側）。同じ日の2回目は増えない。
- 送る間、ブラウザの通信先が 127.0.0.1 だけ（AC-056 の一部）。
