# SC-02 アバター選択（画面設計）

作成: 2026-11-09 15:06（実測） / 到達点: M3 / モック: `docs/10_企画/画面モック/SC-02_アバター選択.html`（1対1。index.html に無い画面なので、同じ色・角丸で単体のモックを作った）
上流: 方向性 §5・§18（絵の置き場・`<img>`・シルエット）、要件定義 R-006・R-007、ユーザー指示 2026-11-09 14:00（4枚そろった体だけ選べる）。

## 1. 目的
いっしょに旅する相棒（アバター）を選ぶ。選んだ相棒がホームの吹き出し・すごろくの駒・声になる（「自分の相棒と旅をしている」気持ち。US-016）。

## 2. 対応
| 種類 | 番号 |
|------|------|
| 要件 | R-006（4体・既定ともにゃん・4枚そろった体だけ選べる・準備中はシルエット）、R-007（`<img>`・alt）、R-035・R-036、R-055 |
| ストーリー | US-016 |
| 受け入れ基準 | AC-007、AC-008（画面側の「準備中」）、AC-009 |

## 3. 要素（上から順）
| # | 要素 | 内容・ルール | データ |
|---|------|--------------|--------|
| 1 | ヘッダー | 左に「もどる」（48px、`aria-label="もどる"`）、h1「相棒をえらぶ」、右に設定（歯車） | — |
| 2 | 説明 | 「いっしょに旅する相棒を選んでね。選ぶとホームにもどります。」 | — |
| 3 | 相棒のカード（2列×2段） | 4体を ともにゃん・ほしろう・ぴっこん・とうじい の順に並べる。各カードは1つの `<button>`（高さ 168px 程度）: happy の絵を `<img>`（96px、alt「名前（にこにこ）」）、名前（太字）、ひとこと紹介（ともにゃん「灯りの猫・のんびり」、ほしろう「星空好きの子・元気」、ぴっこん「お堀の小鳥・さっぱり」、とうじい「お城の見回り番・ていねい」）。いまの相棒は `aria-pressed="true"`、主色の枠と「いまの相棒」のチップ（チェックの印つき） | API 3 `[{ id, available }]`・`MeState.profile.avatar` |
| 4 | 準備中のカード | `available:false` の体は、同じ happy の絵を CSS の `filter: brightness(0)` と薄い不透明度でシルエットにし、「準備中」のチップと名前の文字を添える。`aria-disabled="true"`、押すと「準備中です。もうしばらく待ってね」のお知らせ（選べない） | `available` |
| 5 | 注記 | 「絵はこのアプリのために作ったものです。声は設定で変えられます。」【仮定】 | — |

- 下の操作バーと下のメニューは出さない（サブ画面。方向性 §19.1）。
- **既定はともにゃん**（利用開始時の `profile.avatar = 'tomonyan'`）。
- いまは4体とも4枚そろっているので、4体とも選べる（2026-11-09 15:06 に `docs/10_企画/アバター/` の SVG 16枚を確認）。

## 4. 状態
| 状態 | 画面 | 次の行動 |
|------|------|----------|
| 読み込み中 | カードの場所に灰色の枠4つと「読み込み中…」（`role="status"`） | 待つ |
| 空 | サーバーの一覧が0件になることは無い（マスタ固定）。万一0件なら「相棒を読み込めませんでした」とエラーと同じ扱い | もう一度 |
| エラー | 一覧の失敗:「うまくいきませんでした。少し待ってから もう一度ためしてね。」と「もう一度」。選ぶのに失敗（400 など）: 同じ文と「もう一度」。選び直しはしない | もう一度・もどる |
| オフライン | 同じ PC のサーバーなので、ネットが切れても選べる。**地図が無いので「オフライン表示中」は出さない** | そのまま使う |
| 送信中 | 押したカードに「えらんでいます…」、ほかのカードも押せない（二重送信を防ぐ） | 待つ |
| 選んだ後 | ホームへ戻り、「（名前）が相棒になったよ」のお知らせ（`role="status"`） | — |
| 準備中を押した | お知らせ「準備中です。もうしばらく待ってね」 | ほかの体を選ぶ |

## 8. アクセシビリティ（WCAG 2.2 AA）
| 達成基準 | 確認の観点 |
|----------|------------|
| 1.1.1 | 絵の alt が「名前（にこにこ）」。シルエットの絵も alt は「名前（準備中）」とし、名前の文字も出す（形だけに頼らない） |
| 1.3.1 | 4枚のカードは `<ul>` の中の `<button>`。h1 のあとに説明 |
| 1.4.1 | いまの相棒は枠の色だけでなく「いまの相棒」の文字とチェック。準備中は黒い形だけでなく「準備中」の文字 |
| 1.4.11 | 選ばれた枠（#0E7C74）と白いカードの差 3:1 以上を M4 で計算 |
| 2.1.1 | Tab でカードを移り Enter／Space で選べる |
| 2.5.3 | ボタンの名前は「ともにゃん 灯りの猫・のんびり」のように見える文字を含む |
| 2.5.8 | カードは 44px を大きく超える（約 165×168px） |
| 3.2.2 | 選ぶ操作は「押した」ときだけ（フォーカスで選ばない）。押した結果ホームへ戻ることは説明文で前もって書く |
| 4.1.2 | いまの相棒は `aria-pressed="true"`、準備中は `aria-disabled="true"` |
| 4.1.3 | 「（名前）が相棒になったよ」「準備中です」を `role="status"` で知らせる |

- 使いにくくなる人と対策（INC-01）: 絵の違いが見えにくい人→名前と紹介を文字で。色が分かりにくい人→「いまの相棒」の文字。
- だれのための工夫か（INC-03）: 大きなカードは手の細かい動きが難しい人のためだが、子ども（P-06）や歩きながらの操作にも効く。

## 9. M4 の E2E で確かめる観点
- 初めて開いたときはともにゃんが「いまの相棒」（AC-007）。
- ほしろうを選ぶとホームへ戻り、ホームの絵（alt「ほしろう（にこにこ）」）と、すごろくの駒の絵（`/avatars/hoshirou-happy.svg`）が替わる（AC-007・AC-009）。
- 4枚そろわない体は「準備中」で選べない（サーバーの一覧が `available:false` のとき。AC-008 は U の試験、画面は偽の一覧で確かめる）。
- キーボードだけで選べる（AC-063 の一部）。

## 10. index.html との関係
- index.html には無い画面（ホームの「変更」は「省略しています」）。色・角丸・影・ボタンの形は index.html の CSS 変数（`--main`・`--accent`・`--card`・`--sh`、カード角丸 24px）に合わせる。

## 11. 【仮定】
- 見出しは「相棒をえらぶ」。各体の紹介文は方向性 §5 の設定から短くした。
- 選んだときに相棒の声で自動で話させない（開いた画面で自動で読まない方針に合わせる）。
- シルエットの alt は「名前（準備中）」。
