# SC-06 うわさ（画面設計）

作成: 2026-11-09 15:06（実測） / 到達点: M3 / モック: `docs/10_企画/画面モック/SC-06_うわさ.html`（1対1。見た目の正は `index.html#rumor`。index.html に無い「過去1か月の人気」と、年齢層・一緒に来た人を分けた2つの見本を足した）
上流: 方向性 §6「うわさ」・§19.9、データ設計 §4.3・§5、ADR-009、要件定義 R-027。

## 1. 目的
みんなの動き（CSV 由来の集計。ダミー）から、**次に行く場所と空いている時間を見つける**。自分と同じ年代・同じ一緒に来た人の行き先が分かると、「次はあそこへ」と思える。

## 2. 対応
| 種類 | 番号 |
|------|------|
| 要件 | R-027（5種の集計・集計値だけ）、R-002（選ぶと出る）、R-057（個人に見える値を出さない）、R-055 |
| ストーリー | US-005（同じ年代・空いている時間）、US-024（元データ） |
| 受け入れ基準 | AC-034（画面側の「選ぶと出ます」）、AC-064 |

## 3. 要素（上から順）
| # | 要素 | 内容・ルール | データ |
|---|------|--------------|--------|
| 1 | ヘッダー | h1「うわさ」、右に設定 | — |
| 2 | 説明 | 「みんなの動きから、次に行く場所を見つけよう」 | — |
| 3 | 昨日の人気 | h2。カードにランキング3行（順位の丸・スポット名・人数の棒・「n人」・＞）。1位の丸は金 | API 13 `yesterday` |
| 4 | 過去1か月の人気（index.html に無い。足す） | h2。同じ形の3行 | `month` |
| 5 | 同じ年齢層に人気 | h2「20代に人気」。年齢が「選ばない」のときは、行の代わりに「ホームの『はじめに選んでね』で年齢を選ぶと出ます」とボタン「選びに行く」→ SC-01 | `sameAge`（null なら未選択） |
| 6 | 同じ一緒に来た人に人気 | h2「友達と来た人に人気」。未選択のときは同じ案内 | `sameCompanion` |
| 7 | 空いている時間帯 | h2「空いている時間帯：名古屋城」。スポットの `<select>`（`<label>`「スポット」、既定は名古屋城）【仮定】。9〜17時の棒グラフ（空いている時間は金の棒と「空き」の文字）。グラフは `role="img"` で「9時 空き、10時、…」の名前 | `quiet`（`?spot=`） |
| 8 | 注記 | 「ダミーの集計です」 | — |
| 9 | 下のメニュー | うわさ（`aria-current="page"`） | — |

- 各ランキングの行を押すと、そのスポットの詳細（SC-04）へ。
- 人数の棒は飾り（`aria-hidden`）。人数は「n人」の文字で出す。利用者の ID・名前は出さない（応答にも無い）。

## 4. 状態
| 状態 | 画面 | 次の行動 |
|------|------|----------|
| 読み込み中 | 各カードに灰色の行3つと「読み込み中…」（`role="status"`） | 待つ |
| 空 | 集計が0件の種類は「まだ集計がありません」【仮定】。年齢・一緒に来た人が未選択なら #5・#6 の案内 | ホームで選ぶ |
| エラー | 「うまくいきませんでした。少し待ってから もう一度ためしてね。」と「もう一度」 | もう一度 |
| オフライン | 同じ PC のサーバーの集計なので、ネットが切れても見られる。**地図が無いので「オフライン表示中」は出さない** | そのまま使う |
| スポットを変えた | 空いている時間帯だけ取り直す（ほかのカードはそのまま） | — |

## 8. アクセシビリティ（WCAG 2.2 AA）
| 達成基準 | 確認の観点 |
|----------|------------|
| 1.1.1 | 棒グラフは `role="img"` と、時間と「空き」を並べた名前。人数の棒は `aria-hidden` |
| 1.3.1 / 2.4.6 | h1 → h2（5種）。ランキングは `<ol>` の中の `<button>` |
| 1.4.1 | 空いている時間は金の色だけでなく「空き」の文字。1位は金の丸と数字「1」 |
| 1.4.3 | 「空き」の文字（#6B4A00／#FFF1D2）、人数（#55625F／白）を M4 で計算 |
| 2.4.4 | 行の名前は「1 東山動植物園 128人」 |
| 2.5.8 | 行 56px、select 52px |
| 3.2.2 | スポットを選んでも画面は移らない（グラフだけ替わる） |
| 3.3.2 | select に「スポット」のラベル |
| 4.1.3 | 取り直し中・失敗を `role="status"`／`role="alert"` で |

- 使いにくくなる人と対策（INC-01）: グラフが読めない人→「空き」の文字と名前。色が分かりにくい人→文字。
- だれのための工夫か（INC-03）: 空いている時間は混雑が苦手な人のためだが、車いす・ベビーカー・高齢者にも効く。

## 9. M4 の E2E で確かめる観点
- 5種（昨日・過去1か月・同じ年齢層・同じ一緒に来た人・空いている時間帯）が出る。年齢・一緒に来た人が未選択なら「選ぶと出ます」の案内（AC-034 の画面側）。
- 行を押すと SC-04（スポット名が h1）。
- 画面の文字に人の名前・ID が無い（AC-066 の画面側）。
- API を止めると「もう一度」（AC-064）。

## 10. index.html との違い
1. 「過去1か月の人気」を足す（R-027 の5種）。
2. index.html の「（年代）・（一緒に来た人）に人気」1つを、「同じ年齢層」と「同じ一緒に来た人」の2つに分ける（R-027、API の `sameAge`・`sameCompanion`）。
3. 空いている時間帯のスポットを選べるようにする（API 13 の `spot`）。

## 11. 【仮定】
- 空いている時間帯のスポットを select で選べる。
- 集計が0件の種類の文言「まだ集計がありません」。
