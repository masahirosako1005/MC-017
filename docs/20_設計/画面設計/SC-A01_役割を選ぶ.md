# SC-A01 役割を選ぶ（画面設計）

作成: 2026-11-09 15:33（実測） / 位置づけ: 追加企画（運営画面）。要件定義へは未反映 / モック: `docs/10_企画/画面モック/SC-A01_役割を選ぶ.html`（1対1。見た目の正は `admin.html#a01`）
上流: 運営向け画面_仕様案 §2（利用者と権限・ADMIN_MODE）、§5（画面一覧 SC-A01）、§5.1（画面の約束）。

## 1. 目的
ログインを作らない代わりに、**だれとして運営画面を使うか（観光協会か、どの店舗か）**を最初に選ぶ。役割が決まると、観光協会は「何に困っているか／どうしたら再訪につながるか」の分析（SC-A02 から）へ、店舗は自店の数字（SC-A10 から）へ進む。店舗は**自分の店の数字だけ**を見る、という約束をこの画面で伝える。

- 使いにくくなる人と対策（INC-01）: 機械に慣れていない店主→店の名前そのままをプルダウンで選べ、言葉の説明が要らない。選び忘れたら文字で教える。
- だれのための工夫か（INC-03）: 店の名前で選べるのはレジ横のタブレットで使う店主のためだが、店が増えてもトップの画面が長くならないので、複数の店を見る観光協会の担当にも分かりやすい。

## 9. 試験で確かめる観点（仕様案 §9 から。合否は書かない）
- 権限: `ADMIN_MODE` なしでは `/admin` も `/api/admin/*` も 404（`Cannot GET` を出さず、自前の 404 と同じヘッダ）。
- 権限: 店舗の役割を選ぶと、左のメニューに自店の画面だけが出る。店舗の役割で観光協会の画面（例: SC-A02）の API を呼ぶと 404。
- 画面: 店を選ばずに「このお店で進む」を押すと進まず、メッセージが出てプルダウンにフォーカスが戻る。店を選ぶと、選んだ店の役割（`shop-s8`・`shop-s9`・`shop-s11`）で次へ進む。トップの選びは「観光協会」「店舗」の2つだけで、店ごとのカードが無い。
- 入力: `X-Operator` が許可リスト外（例 `shop-s1`・空・2つ指定）なら 400。
- アクセシビリティ: キーボードだけで役割を選べる、200% 拡大で横に流れない。

## 10. 【仮定】
- 役割は `sessionStorage` に覚え、タブを閉じたら消える。保存が使えないときは画面を開いている間だけ覚える。
- 店の名前（あかり堂・きしめん ひだまり・みそかつ こもれび）は画面の辞書に固定で持ち、プルダウンの選択肢にする。API を呼ばない。
- 店のプルダウンの先頭は「お店をえらんでください」（未選択）。店を選ぶまで進めない（既定の店は置かない）。モックでは、どの店を選んでもあかり堂の画面を出す。
- この画面では上の帯の期間の選択を出さない。
- 役割を決めずに他の画面を開いたら、この画面に切り替えて「先に役割をえらんでください」と出す。
- `X-Operator` が無い・許可リスト外のときは 400（`bad_request`）。役割が合わないときの 404 とは分ける。
- 役割を変えたら、前の役割で読んだ数字を画面から捨てる（店舗の数字が観光協会の画面に残らないように、またその逆）。
