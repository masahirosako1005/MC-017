# SC-12 設定（デモ操作・ライセンスと出典を含む）（画面設計）

作成: 2026-11-09 15:06（実測） / 到達点: M3 / モック: `docs/10_企画/画面モック/SC-12_設定.html`（1対1。見た目の正は `index.html#settings`。index.html と違う「ことば」「音声（声の選択・いまの声）」「ライセンスと出典」「デモ操作」を静的な見本で足した）
上流: 方向性 §4・§17.3・§19.11、ADR-008（アプリ内の今日と DEMO_MODE）・ADR-011（VOICEVOX）、要件定義 R-035〜R-038・R-043〜R-046、`音声合成の準備.md`（ADR-011 経由）。

## 1. 目的
ことば・文字の大きさ・音声を、**選ぶとすぐ変わる**形で切り替える（保存ボタンなし）。いまの声の名前と、使っている地図・ソフト・声のライセンスと出典を見せる。**DEMO_MODE=1 のときだけ**、発表用に日時・いる場所・さいころの回数を動かす。

## 4. 状態
| 状態 | 画面 | 次の行動 |
|------|------|----------|
| 読み込み中 | 「いまの声：確かめています…」（API 16 の応答待ち）。デモのカードは API 2 が返るまで出さない | 待つ |
| 空 | 端末に声が無い・読み上げなし:「いまの声：なし（文字だけ）」。デモで「いる場所」を選んでいない:「選ばない」 | — |
| エラー | デモ操作の失敗:「うまくいきませんでした。少し待ってから もう一度ためしてね。」と「もう一度」。声の状態が取れない・VOICEVOX が止まっている: 「いまの声：VOICEVOX が起動していません（文字だけ）」（声が VOICEVOX のとき）。ブラウザの声を選んでいればその声の名前 | もう一度 |
| オフライン | 同じ PC のサーバーなので、ネットが切れても全部使える。**地図が無いので「オフライン表示中」は出さない** | そのまま使う |
| DEMO_MODE なし | #7 のカードを出さない（DOM にも入れない）。サーバーもデモの API を 404 にする | — |
| デモの送信中 | デモのボタンは押せない | 待つ |

## 8. アクセシビリティ（WCAG 2.2 AA）
| 達成基準 | 確認の観点 |
|----------|------------|
| 1.3.1 / 2.4.6 | h1 → h2（ことば・文字の大きさ・音声・ライセンスと出典・デモ操作）。ライセンスは `<dl>`。select に `<label>` |
| 1.4.2 | 読み上げ「なし」で再生中の声がすぐ止まる。効果音も止められる |
| 1.4.3 | 切り替えの選ばれた文字（白／#0E7C74）と選ばれていない文字（#09594F／#F0F8F6）を M4 で計算 |
| 1.4.4 | 文字「大」で横スクロールが出ない（AC-044） |
| 2.4.4 | リンク名「出典：地理院タイル」「VOICEVOX ENGINE の配布元」で目的が分かる |
| 2.4.5 | #8「すべての画面」で、SC-02・SC-09 など入口が1つの画面にも2つ目の行き方がある（SC-04・SC-06〜SC-08 はスポットを決めてから開く手順の一部のため対象外【仮定】） |
| 2.5.8 | 切り替え 50px、デモのボタン 48px、select 52px |
| 3.1.1 / 3.1.2 | English のとき `<html lang="en">`。日本語のとき、English のボタンに `lang="en"` |
| 3.2.2 | 選ぶとすぐ反映するが画面は移らない |
| 4.1.2 | 切り替えは `aria-pressed`、グループに `aria-label` |
| 4.1.3 | 「アプリ内の今日を…にしました」などを `role="status"` で |

- 使いにくくなる人と対策（INC-01）: 文字が小さく読めない人→文字の大きさ。聞こえない人→読み上げはいつも文字と一緒。日本語が読めない人→English。声で読まれると困る場所→読み上げ「なし」。
- だれのための工夫か（INC-03）: 文字の大きさは高齢者（P-03）のためだが、屋外のまぶしい所で読む人にも効く。

## 9. M4 の E2E で確かめる観点
- English にすると主要画面が英語になり `<html lang="en">`（AC-043）。
- 文字「大」で 390px の主要画面に横スクロールが無い（AC-044）。
- いまの声の名前が出る。読み上げ「なし」で再生中の声が止まる。「ブラウザの声」で `/api/tts` を呼ばない（AC-045）。
- 「ライセンスと出典」に地理院タイル（リンク）・Leaflet（BSD-2-Clause）・VOICEVOX ENGINE（LGPL v3・配布元）・VOICEVOX:話者名4体・公式とは関係ない旨・自作の絵（AC-046）。
- DEMO_MODE なし（3100）ではデモ操作が無く、DEMO_MODE=1（3000）では出る（AC-052）。
- デモで＋7日→ホームのあいさつが「再訪」（AC-053 の画面側）、いる場所→SC-03 に「いまここ（デモ）」（AC-054）、さいころ ＋5→SC-05 の回数が5増える（AC-055 の画面側）。

## 10. index.html との違い（後の指示を採る）
1. ことばは「標準語・ひらがな・English」ではなく **日本語／English**（ひらがなは Could の R-060）。
2. 読み上げの説明は「吹き出しに読み上げボタンが出ます。自動では読みません。」ではなく「**操作のあと、相棒のセリフを吹き出しと同時に読みます**」（方向性 §17.3）。
3. **声：VOICEVOX／ブラウザの声** と **いまの声の名前** を足す（R-037）。
4. **ライセンスと出典** を足す（R-038）。
5. **デモ操作**（DEMO_MODE=1 のときだけ）を足す（R-043〜R-046）。
6. 「すごろく 遊ぶ／遊ばない」（Should の R-039）は出さない。
7. **すべての画面** を足す（WCAG 2.4.5。M3 ゲートで FAIL だったため）。

## 11. 【仮定】
- デモの「もとに戻す」（offsetDays 0・時刻は自動）。
- 時刻の select は 0〜23時と「自動」。
- 「そのほか」のソフトの名前とライセンスの一覧を「ライセンスと出典」に並べる。
- 吹き出しの「読み上げ」ボタンは残す（もう一度聞くため）。
- 「すべての画面」は設定の中に置く（歯車はすべての画面にあるため）。SC-04・SC-06〜SC-08 はスポットを選んでから開く手順の途中の画面なので一覧に入れない（WCAG 2.4.5 の「手順の一部」の例外）。
