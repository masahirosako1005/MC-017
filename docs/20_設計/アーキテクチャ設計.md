- 1ポートで配信（本番相当）: `npm run build` で `dist/client` を作り、Express が静的配信と `/api` を受け持つ。開発は Vite（127.0.0.1:5173）が `/api` を 3000 へ proxy（environment ルール）。

## 3. サーバーの層（coding ルール）
| 層 | 置き場 | 役割 | してはいけないこと |
|----|--------|------|--------------------|
| route | `routes/*.ts` | zod で `params`・`query`・`body` とヘッダ `X-Guest-Id` を検証し、service を呼んで JSON を返す | SQL・業務ルール |
| service | `services/*.ts` | 業務ルール（回数・1日1回・再訪の判定・予言・クーポンの状態・時計） | HTTP・SQL |
| repository | `repositories/*.ts` | SQL（プレースホルダのみ）。`better-sqlite3` を import するのはここと `db.ts`・取込・試験だけ | 業務ルール |
- ルート登録は `routes/index.ts` に集める（parallel ルールの「ルーター」）。デモの route は **DEMO_MODE=1 のときだけ登録**する（R-043、ADR-008）。
- 複数行の更新（さいころ・答え合わせ・取込）は repository の `transaction` で包む（R-056）。
- 状態を変える POST は `requestId` で1回だけ記録する（R-053、ADR-006）。

## 4. 起動の順番（`main.ts`）
1. 環境変数を zod で読む（`PORT`=3000、`DB_PATH`=`data/app.db`、`SAMPLE_DATA_DIR`=`C:\AI-Sprint\sample-data`、`DEMO_MODE`、`VOICEVOX_PORT`=50021、`AVATAR_DIR`）。不正なら日本語の1行で終了（QL-ZOD-04）。
2. DB を開き `PRAGMA foreign_keys = ON`、`db/schema.sql` を流す（`CREATE TABLE IF NOT EXISTS`）。
3. マスタ（スポット・盤・クーポンの型）を `INSERT OR IGNORE` で入れる。
4. CSV を取り込む（冪等。件数と除外をログ。ADR-009）。CSV が無ければ日本語のエラーで終了（competition ルール）。
5. `127.0.0.1` で listen。listen の後に VOICEVOX を短い文で温める（失敗してもサーバーは止めない。R-040）。
- `uncaughtException` はログして終了する（SEC-ERR-05）。

## 5. 画面の作り（クライアント）
- ルーターのライブラリは入れず、index.html のモックと同じ「画面の状態」で切り替える（`screen` と戻り先のスタック）。下のメニューは5つ（ホーム・スポット・遊ぶ・うわさ・特典）。設定は右上の歯車。
- 見た目は `docs/10_企画/画面モック/index.html` を正とし、CSS をほぼそのまま `app/client/src/styles/` に移す（ADR-002）。インラインの `style` 属性は使わず、位置などの動的な値は React の `style`（CSSOM）だけで渡す（CSP `style-src 'self'`、SEC-XSS-05）。
- 文言は `app/client/src/i18n/`（日本語・英語の辞書。アバターごとの話し方を含む）。スポット名などは `app/shared/master` の ja/en。
- 状態: サーバーの状態（`/api/session` の戻り値）を1つのストアに置き、操作のあとに取り直す。
- 読み上げ: `speech.ts` が VOICEVOX（`/api/tts`）→ ブラウザの端末内の声 → 文字だけ、の順に試す（R-040〜R-042）。再生中は口パク（R-007）。
- 地図: Leaflet（ズームは自前の 44px ボタン、出典は自前の表示。ADR-012）。オフラインは同じアイコンの簡易地図（R-010）。

## 6. 配信とヘッダ（ADR-003）
- 全応答の最初に自前のミドルウェアでヘッダを付ける（API・静的・404・エラー）。HSTS は付けない。Helmet は使わない。
- 静的配信は `dist/client` だけ（`dotfiles: 'ignore'`）。`Cache-Control`: `/api` は `no-store`、静的は `no-cache`【仮定】。
- 404 とエラーは自前のハンドラ（`{ error: { code, message } }`、ADR-013）。
