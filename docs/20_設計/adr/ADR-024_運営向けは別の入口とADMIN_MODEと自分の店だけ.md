# ADR-024 運営向けは別の入口・ADMIN_MODE・自分の店だけ
- 状態: 採用
- 日付: 2026-11-10
- 対応: R-070 / R-071 / R-074 / R-075 / R-077 / U-09〜U-12
## 背景
観光協会と店の画面を足す。競技の条件はログインなし・個人情報なし・外部通信なし。利用者アプリの画面・CSS・状態とは別物で、運営向けの画面が利用者に見えてはいけない。店が他店のクーポンを作れてはいけない（指示 2026-11-09）。
## 決定
1. 運営向けは **`ADMIN_MODE=1` のときだけ**登録する（`/admin`・`/api/admin/*`。出さないときは 404 で、存在も見せない）。**2026-11-10 10:14 の人の指示「利用者画面の URL/admin で起動するように」で、既定を `1` にした**（`npm start`・`npm run start:demo` でも `http://127.0.0.1:3000/admin` が開く。`ADMIN_MODE=0` で出さない）。ダミーの利用者を入れる条件は `ADMIN_MODE=1` かつ `DEMO_MODE=1` のまま（`start:demo` で入る）。E2E の 3000・3100 のサーバーは `ADMIN_MODE=0` に固定し、既存の試験を変えない。`npm run start:admin` は `start:demo` と同じ意味で残す（VOICEVOX は起動しない）。ログインなしの運営向けが既定で出るが、`127.0.0.1` のみ listen・個人情報なし・ダミー ID の前提（競技ルール）は変わらない【仮定】。
2. 画面は **別の HTML 入口 `admin.html`**（`/src/admin/main.tsx`）にする。利用者アプリの CSS・i18n・状態を読み込まない。Vite の入力を2つにし、Express は `/admin` で `admin.html` を返す。
3. 役割は **`X-Operator` ヘッダ**（`association`・`shop-s8`・`shop-s9`・`shop-s11`）を zod の enum で検証する。ログインは作らない（ダミー。`X-Guest-Id` と同じ考え方）。
4. **自分の店だけ**: 店の項目はすべて URL の `:shopId` から取り、本文に店の項目を持たせない（`z.strictObject` で拒否）。URL の店が `X-Operator` の店と違えば **404**（観光協会も店の中身は見られない。集計の閲覧は店の `summary` だけ許す）。券の `shop_id` はキャンペーンの店から決まる。
5. キャンペーンは**選択式**（品・円引き・％引き）で、表示名はサーバーが作る。自由入力が無いので他店の名前・連絡先は入らない。保存する状態は `pending` / `approved` / `rejected`、「予定・実施中・終了」は日付から計算する（`phase`）。実施中かどうかを日付の経過で書き換えない。
6. 盤の 🏪 は、承認済みで期間中のキャンペーンについて、対象の人の盤に**人とキャンペーンから決まる位置**へ置き（`board_extras` に保存）、開き直しても動かさない。
## 理由
- 別の入口にすれば、運営向けの CSS・コードが利用者の画面に影響しない。出さないときの 404 で存在が分からない。
- 役割の URL とヘッダの一致だけで、他店の作成・閲覧を防げる（本文に店を持たせない）。
- 日付から計算する状態は、時計を進めても（デモ）ずれず、更新の取りこぼしが無い。
## 検討した代替案（採らなかった理由）
- 利用者アプリの中に `/admin` の画面を足す: CSS・状態が混ざり、利用者の bundle に運営向けが入る。
- ログインを作る: 競技の条件（ログインなし）に反する。
- 状態に `active`・`ended` を持たせ、起動時や読み出し時に更新する: 時計が人ごとに違う（デモ）ので不整合になりやすい。
## 結果・影響（良い点・悪い点・注意）
良い点: 利用者アプリに影響しない・他店を触れない・再現できる。悪い点: ヘッダだけの役割なので、**実運用では使えない**（認証が要る）。注意: `X-Operator` は端末内の操作の区別であり、安全な認証ではない【仮定: 競技では localhost のみ】。
## 【仮定】（資料にない前提。無ければ「なし」）
役割はヘッダで足りる（localhost のみ・ログインなしの競技条件）。運営の「今日」は実際の今日（JST）で、利用者のデモの日付とは別。
