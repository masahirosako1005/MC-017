# ADR-012 地図（Leaflet）とオフラインの判定・簡易地図
- 状態: 採用
- 日付: 2026-11-09
- 対応: R-008〜R-011 / R-045 / AC-011〜AC-015 / AC-054 / U-01 / U-02
## 背景
competition ルール: Leaflet＋地理院の淡色地図、「出典：地理院タイル」を常時、オフライン（`navigator.onLine` とタイルの連続エラーで判定）は同じアイコンの簡易地図＋「オフライン表示中」、戻れば自動で通常の地図。タイルの一括取得はしない。ux ルール: 44px、ドラッグの代替、出典を隠さない。
## 決定
1. Leaflet の既定のズームボタン（30px）と出典の欄は使わず（`zoomControl:false`・`attributionControl:false`）、index.html と同じ 46px の自前ボタンと、左上の出典のプレート（リンク）を地図の外側の層に重ねる。ズームは 11〜17。
2. マーカーは `L.divIcon` に DOM の要素（ボタンの見た目のピン＋ラベル）を渡す（文字列の HTML を渡さない）。キーボードで選べるよう `keyboard: true`、名前は `aria-label`。
3. オフラインの判定: `navigator.onLine === false` か、タイルの `tileerror` が成功をはさまず3回続いたら簡易地図。戻る判定: `online` イベント、または簡易地図の間 15 秒ごとに「次に表示するタイル1枚」の読み込みを試し、成功したら通常の地図（ブラウザの `Image` で1枚だけ。先読みではない）。
4. 簡易地図は、スポットの緯度経度を表示枠に直線で置いた自前の SVG と、**Leaflet と同じアイコン部品**（同じパスのデータと CSS）。出典のプレートはそのまま残し、「オフライン表示中」のバッジを `aria-live="polite"` で出す。
5. ドラッグの代替: 拡大・縮小のボタン、アイコンへの Tab と Enter／Space、選んだスポットへ地図を動かす。（一覧（R-011）は 2026-11-09 の人の判断で削除、ADR-021）
## 理由
自前のボタンとプレートで 44px と「隠れない出典」を守れる。DOM 要素のマーカーなら innerHTML を使わない。1枚だけの再確認なら「表示に必要なタイルをその都度読む」の範囲に収まる【仮定】。
## 検討した代替案（採らなかった理由）
- Leaflet のアトリビューションの欄: 右下で下のメニューに近く、文字が小さい。
- Service Worker でタイルを蓄える: タイルの事前キャッシュに当たり禁止。
## 結果・影響（良い点・悪い点・注意）
良い点: 制約と WCAG 2.2 を両方守れる。悪い点: 簡易地図は道や川が無い（アイコンと地名だけ）。注意: E2E ではタイルを `page.route` で差し替え、失敗させてオフラインを再現する（ADR-015）。
## 【仮定】（資料にない前提。無ければ「なし」）
連続3回・15秒・ズーム 11〜17・簡易地図の描き方。
