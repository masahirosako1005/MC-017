# ADR-010 予言の計算（LLM を呼ばない決まった点数）
- 状態: 採用
- 日付: 2026-11-09
- 対応: R-030〜R-033 / AC-038〜AC-042 / U-06
## 背景
補強案B（人の選択 12:37）。予言は LLM・外部 API なしの決まった計算で、理由を3つまで見せる。SC-09 §4 で重みと式は M3 で確定するとした。
## 決定
候補（行っていない sight・event。段差少なめの人は段差なしだけ）ごとに点数を足す（`app/shared/prophecy.ts` の純粋関数）。
| 要素 | 点 | 理由の code |
|------|----|-------------|
| 自分の好み | 候補のタグごとに「自分が行ったスポットにそのタグがあった数 × 1.0 ＋ 学習の重み」 | `tag`（いちばん大きいタグ） |
| 似た人の行き先 | 3.0 × 「同じ年齢層・同じ一緒に来た人で、自分が行ったスポットのどれかに行った CSV の利用者のうち、候補にも行った人の割合」（年齢・一緒に来た人が未選択なら全員） | `similar` |
| 次の季節 | 候補の季節がアプリ内の今日の次の季節なら 1.5 | `season` |
| 段差少なめ | 段差少なめを選んだ人で、候補が段差なしなら 1.0 | `stepfree` |
- 点数の高い順。同点はスポット ID の並び（s1 < s2 < … < s10 < s11）で毎回同じ。2位・3位は「ほかの候補」。
- 理由は点の大きい順に3つまで。強さ: 2.0 以上「強い」、1.0 以上「中くらい」、それ未満「弱い」。0点の要素は出さない。
- 「いつ」: 候補の季節（通年なら次の季節）と、自分がよく QR を読む時間帯（朝 5〜10・昼 11〜15・夕方 16〜18・夜 19〜4、記録が無ければ昼）。
- 学習: 気に入った → 予言のスポットのタグの重み +0.5、ふつう → −0.5（−2〜3 の範囲）。あとで答える → 変えない。
- かしこさ: 答え合わせの回数 0・1・3・5・8 でレベル 1〜5。的中率 = 気に入った ÷（気に入った＋ふつう）。
## 理由
足し算だけなので理由をそのまま見せられ、同じ入力で同じ結果になり、Vitest で点数・順位・理由を確かめられる。似た人の割合は CSV の共起の集計で、「みんなの旅から考えた」と言える。
## 検討した代替案（採らなかった理由）
- 機械学習のライブラリ: 依存が増え、理由を説明しにくい。
- 乱数で選ぶ: 当たる理由が無く、「AI らしさ」にならない。
## 結果・影響（良い点・悪い点・注意）
良い点: 説明できる・試験できる。悪い点: スポットが10か所なので、何度か来ると候補が尽きる → 候補が0なら「全部行ったにゃ。次の季節のイベントを見よう」と出し、行ったスポットも候補に戻す【仮定】。注意: 重みは仮の値。デモで違和感があれば ADR を足して直す。
## 【仮定】（資料にない前提。無ければ「なし」）
重み（1.0・3.0・1.5・1.0・±0.5）、強さの境目、時間帯の区切り、候補が尽きたときの扱い。
