# ADR-011 VOICEVOX を別のプログラムとして 127.0.0.1 で呼び、無ければブラウザの読み上げ
- 状態: 採用
- 日付: 2026-11-09
- 対応: R-040 / R-041 / R-042 / R-037 / R-038 / R-007 / AC-047〜AC-050 / U-01
## 背景
声は VOICEVOX（方向性 §17、ユーザー指示 13:08・14:00）。VOICEVOX ENGINE は LGPL v3（と別ライセンスのデュアル）で、OSS の許可リスト（MIT/BSD/Apache/ISC）の外。エンジンは同じ PC で別に起動する。エンジンが無くてもアプリは動く必要がある。別のチャットの `音声合成の準備.md`（14:01〜14:13）で、0.26.1 の Windows CPU 版が 127.0.0.1:50021 だけで待ち受け、4話者とも合成でき、起動に約50秒・2回目以降の合成に約1.6〜3.0秒かかることを確かめた。同書 §5 は「実行時に呼ぶ構成（案B）は許可リストの外」と判断を求め、§7 でユーザーは 14:12 に「読み上げを VOICEVOX（`/api/tts`）に切り替え、設定で声を選べ、止まっていればブラウザの声に戻す」と指示した。
## 決定
1. VOICEVOX ENGINE は **npm の依存にせず、提出物にも含めない**。利用者が別に起動したエンジンへ、サーバーが `http://127.0.0.1:{VOICEVOX_PORT}`（既定 50021、ホストは固定）で `audio_query` → `synthesis` を呼ぶだけ。
2. 話者はサーバーの表で固定（ともにゃん 8 春日部つむぎ・ほしろう 70 満別花丸（元気）・ぴっこん 54 春歌ナナ・とうじい 42 ちび式じい）。ともにゃんは `speedScale` 1.1。
3. 失敗（接続できない・10秒で打ち切り・エンジンの誤り）は 503。画面はその画面を開いている間、ブラウザの `speechSynthesis` を使う: 端末内（`localService`）の声だけ、日本語は Nanami を優先、名前に Online を含む声は使わない、無ければ文字だけ。声の選び方は `app/client/src/lib/voice-pick.ts` の純粋関数。
4. VOICEVOX の声で鳴ったときは画面の隅に「VOICEVOX:話者名」を出す。設定の「ライセンスと出典」には4話者のクレジット（`VOICEVOX:春日部つむぎ`・`VOICEVOX:満別花丸`・`VOICEVOX:春歌ナナ`・`VOICEVOX:ちび式じい`）を**常に**テキストで載せ、「このアプリは各キャラクターの公式とは関係ありません」と VOICEVOX ENGINE（LGPL v3・配布元）も載せる。「ななひら」とは書かない。
5. 設定に「声：自動（VOICEVOX 優先）／ブラウザの声」。（**2026-11-09 17:24 に ADR-023 で変更**: 「自動」は VOICEVOX だけにし、止まっていてもブラウザの声へは切り替えない。）ブラウザの声を選んだら `/api/tts` を呼ばない。
6. エンジンの状態はサーバーが持つ。503 の後も、次の要求のとき（前の確認から30秒以上たっていれば）`GET /version` で確かめ直し、あとから起動したエンジンを使う（同書 §7【仮定】）。
7. 試験では実エンジンを使わず、127.0.0.1 の一時ポートで動く偽のエンジンで正常（WAV）と停止（503）を確かめる。実エンジンでの確認は手動（M5）。
## 理由
同じ PC の 127.0.0.1 なので「外部 API・クラウド」に当たらないと考える【仮定】。依存・同梱をしないので、許可リストは「導入する OSS」に当たらないと扱う（方向性 §17.5）。実行時に呼ぶ構成（同書 §5 の案B）はユーザーが 14:12 に選んだ（人の判断）。エンジンが無くても全機能が動く（R-041）。ちび式じいの規約はクレジットなしの利用に利用料を定めるので、クレジットは声の有無にかかわらず設定に常に出す。
## 検討した代替案（採らなかった理由）
- ブラウザの読み上げだけ: ユーザー指示（VOICEVOX）に合わない。ただし扱いが認められない場合の退き先として残す（Must は削らない）。
- 音声を事前に作ってファイルで同梱: キャラクターの声の配布になり、利用規約の確認が重い。音源ファイルを使わない方針（方向性 §16.5）にも反する。
## 結果・影響（良い点・悪い点・注意）
良い点: エンジンがあれば4体それぞれの声、無ければ端末の声か文字。悪い点: エンジンの準備（約2GB・起動約50秒）は利用者の手間で、1文に約2秒待つ。待つ間は文字を先に出す。注意: エンジンからの外部送信の有無は同書でも未確認。ネットを切った状態での確認は M5 の手動確認に入れる。
## 【仮定】（資料にない前提。無ければ「なし」）
LGPL のエンジンを別プログラムとして呼ぶ扱い、`speedScale` の値、10秒の打ち切り、30秒の確かめ直しの間隔。配布元（https://github.com/VOICEVOX/voicevox_engine/releases/tag/0.26.1）は同書で確認済み。
