# ADR-002 画面の正は index.html
- 状態: 採用
- 日付: 2026-11-09
- 対応: R-003 / R-008 / R-012 / R-017 / R-024 / R-027 / R-035 / R-036 / U-01〜U-07
## 背景
画面モックは統合の `docs/10_企画/画面モック/index.html`（12:46）と、先行の SC-04・SC-09 があった。2026-11-09 14:00 のユーザー指示は「画面は index.html を正とし、フロントもその見た目に合わせる」。一方、すごろくの盤（50マス・縦長）と音声は、index.html より後の方向性 §16・§17 で決まった。aidlc ルールはモックと画面設計の1対1を求める。
## 決定
1. 見た目（色・角丸・部品・並び・文言）は index.html を正とする。CSS はほぼそのまま `app/client/src/styles/` へ移す。
2. 画面ごとのモック `SC-xx_*.html` は index.html を複製せず、`index.html#画面` を iframe で出し、index.html に無い部分（50マスの盤・声の名前・デモ操作など）だけ同じ見た目の静的な見本を足す。
3. index.html と後の指示が違う所は後の指示を採る（盤は50マス、読み上げは操作のあと自動、言語は日本語／英語、ひらがなは Could）。各画面設計に明記する。
## 理由
正を1つにすると、実装・モック・設計のずれを確かめやすい。複製するとモック同士がずれる。
## 検討した代替案（採らなかった理由）
- 画面ごとに index.html から切り出して複製: 12ファイルに同じ CSS と JS が入り、保守が重く、ずれる。
- index.html の20マスの盤に合わせる: 方向性 §16 のユーザー指示（50マス）に反する。
## 結果・影響（良い点・悪い点・注意）
良い点: 正が1つ。悪い点: SC-xx の html だけでは全体が見えないので、ブラウザで index.html も開く必要がある。注意: index.html の末尾にハッシュで画面を開く数行を足した（見た目は変えない、14:10）。
## 【仮定】（資料にない前提。無ければ「なし」）
iframe でつなぐ形を1対1とみなすこと。
