# 非機能・セキュリティ設計

作成: 2026-11-09 14:11（ファイルの更新時刻。当初の 14:37 は推測の誤りで訂正） / 到達点: M3（2.6） / 上流: `要件定義.md`（R-050〜R-057）、`security-quality.mdc`、`docs/00_準備/セキュリティ品質チェックリスト.md`（SEC-*・QL-*）、`アクセシビリティチェックリスト.md`。

## 1. HTTP ヘッダ（R-051、ADR-003）
全応答（API・静的・404・エラー）の最初に、自前のミドルウェア `http/headers.ts` で付ける。

| ヘッダ | 値 |
|--------|----|
| Content-Security-Policy | `default-src 'self'; script-src 'self'; connect-src 'self'; img-src 'self' data: https://cyberjapandata.gsi.go.jp; style-src 'self'; media-src blob:; object-src 'none'; base-uri 'none'; frame-ancestors 'none'; form-action 'self'` |
| X-Content-Type-Options | `nosniff` |
| Referrer-Policy | `no-referrer`（ADR-018） |
| X-Frame-Options | `DENY` |
| Permissions-Policy | `accelerometer=(), autoplay=(self), camera=(), display-capture=(), geolocation=(), gyroscope=(), magnetometer=(), microphone=(), midi=(), payment=(), usb=(), serial=(), bluetooth=(), xr-spatial-tracking=(), browsing-topics=()`（autoplay は音声再生のため自分だけ許す。実装 http/headers.ts に合わせた 2026-11-10） |
| Cross-Origin-Opener-Policy | `same-origin` |
| Cross-Origin-Resource-Policy | `same-origin` |
| Cache-Control | `/api/*` は `no-store`、静的は `no-cache` |
- 送らない: `Strict-Transport-Security`（ユーザー指定）、`X-Powered-By`（`app.disable('x-powered-by')`）、`Cross-Origin-Embedder-Policy`、`Access-Control-Allow-Origin`、`X-XSS-Protection`、`Expect-CT`、`Public-Key-Pins`、`Server`。
- `media-src blob:` は VOICEVOX の WAV を Blob の URL で鳴らすため（方向性 §17.3）。rules とチェックリストの CSP に同じ1語を足す（ADR-003）。
- `upgrade-insecure-requests` は入れない（HTTP の localhost のため。SEC-CSP-05）。

## 2. 入力の検証（R-052、ADR-004）
| 対象 | 方法 |
|------|------|
| body | `z.strictObject`（未知キーは 400）。文字列は `min`/`max`、数値は `int`・範囲、列挙は `z.enum` |
| params | `spotId` はスポット ID の列挙、`couponId`・`prophecyId` は `^[1-9][0-9]{0,8}$` の文字列を数に直す |
| query | `/api/rumors` の `spot` だけ。値が配列（`?spot=a&spot=b`）なら 400（SEC-IN-07）。ほかの API は query のキーが1つでもあれば 400（`queryGuard` で一括。運営向けの summary・campaigns・voices も許可リスト。2026-11-10 追加） |
| Host | ホスト名が `127.0.0.1` / `localhost` 以外なら 403（DNS リバインディング対策。ポートは問わず dev の 5173 も通す。`hostGuard`、2026-11-10 追加） |
| ヘッダ | `X-Guest-Id` を `^guest-[a-z0-9]{6}$` で検証（ADR-005） |
| サイズ | `express.json({ limit: '16kb', type: 'application/json' })`。超えると 413 |
| Content-Type | POST・PUT・PATCH で `application/json` 以外は 415（SEC-IN-06） |
| 環境変数・CSV | zod で検証（QL-ZOD-04、SEC-IN-11） |
| ひとこと | 1〜100字（サーバーでも）。前後の空白を除いて空なら 400。改行は許す。HTML として扱わない |
- 検証に失敗したら何も書かずに 400 を返す（SEC-IN-08）。応答にはスキーマの中身を出さず「入力を確かめてください」だけ（QL-ZOD-05）。

## 3. 注入と XSS
- SQL はすべてプレースホルダ（`?`・名前付き）。表名・列名を動的に組み立てない（SEC-SQL-01〜03）。
- 画面は React の通常の描画と `textContent` だけ。`innerHTML`・`dangerouslySetInnerHTML`・`insertAdjacentHTML`・`document.write`・`eval`・`new Function` を使わない（SEC-XSS-01〜07）。Leaflet のマーカーも DOM の要素で作る（`L.divIcon({ html: HTMLElement })`）。
- `href` は固定の URL だけ（地理院の一覧ページ・VOICEVOX の配布元）。
- 試験: AC-019（XSS の文字列が文字のまま出る）、AC-020（SQL 注入の文字列が文字のまま1行だけ保存）。

## 4. 別のサイトからの操作（ADR-005）
- Cookie・セッションを使わない（SEC-NODE-12）。利用者はヘッダ `X-Guest-Id` で送るので、別のサイトのフォームからは送れない（フォームは独自ヘッダを付けられない）。
- さらに、状態を変える要求で `Origin` があり自分以外なら 403。JSON 以外の Content-Type は 415（SEC-NODE-13）。
- 認可: API は利用者 ID を URL や body で受けない。クーポン・予言は ID と `X-Guest-Id` の両方が合うときだけ（他人のものは 404。SEC-SQL-08）。

- 運営向け API（ADMIN_MODE=1 のときだけ）は X-Operator ヘッダで役割を決めるだけで認証は無い【仮定】（ログインなしの制約・ダミー）。ADMIN_MODE を切れば /api/admin/*・/admin は存在しない。localhost 限定の試作の範囲で受容し、本番相当では認証が要る（残余リスク）。/api/admin/* は X-Operator を z.enum で検証し、他店の URL は 404。

## 5. エラーとログ（ADR-013）
- 404 とエラーは自前のハンドラで返す。`Cannot GET` を出さない（SEC-HDR-15）。5xx は `internal` だけ返し、詳細はサーバーのログへ（SEC-ERR-01〜03）。
- ログは `console` に1行の JSON（時刻・種類・件数・状態コード）。ひとことの本文・リクエスト本文全体・ダミー ID 以外の識別子は出さない。値の改行は `\n` にする（SEC-IN-13・SEC-ERR-09）。
- `uncaughtException` はログして `process.exit(1)`（SEC-ERR-05）。

## 6. 外部通信（R-050）
| 通信 | 許すか |
|------|--------|
| ブラウザ → 127.0.0.1:3000 | ○ |
| ブラウザ → `https://cyberjapandata.gsi.go.jp/xyz/pale/{z}/{x}/{y}.png`（表示に要るタイルだけ） | ○（CSP の img-src） |
| サーバー → `http://127.0.0.1:{VOICEVOX_PORT}`（/api/tts のときと起動時の温め） | ○（同じ PC） |
| それ以外（CDN・Web フォント・LLM・外部 API・LINE） | × |
- タイルの一括ダウンロード・先読み・Service Worker は作らない。
- 試験: E2E で `page.on('request')` の宛先を集め、127.0.0.1 と地理院だけを確かめる（AC-056）。E2E ではタイルを `page.route` で差し替え（オンラインは 1×1 の PNG、オフラインは失敗）、実際の地理院へは出ない（ADR-015）。

## 7. データ完全性（R-056）
- 制約は `データ設計.md` §3。さいころ・答え合わせ・クーポンを使う・取込は1トランザクション。
- 二重送信: `requests` 表（ADR-006）と、一意キー（`grants`・`stamps`・`coupons`）の二重の守り。

## 8. アクセシビリティ（R-054、WCAG 2.2 AA）
| 観点 | 設計 |
|------|------|
| 幅 | 360〜430px で横スクロールなし。PC は中央に最大幅 430px（ux ルール）。試験は 390px・430px（AC-062） |
| 文字 | 小・中・大（15・17・20px を `<html>` のクラスで）。大で崩れない（AC-044）。200% 拡大は M5 で手動 |
| 操作 | 操作要素は 44px 以上、間隔 8px。主な操作は画面の下（`.act`） |
| キーボード | すべてボタン要素。フォーカスは `:focus-visible` の 3px の線。固定の下のメニュー・出典で隠さない（2.4.11） |
| 色 | 🎁マスは黄色＋アイコン＋文字。予言の結果は ○・△ の記号と文字（1.4.1） |
| 動き | `prefers-reduced-motion` で、さいころ約0.5秒・駒は跳ねない・紙吹雪は少なく・口パクしない（2.3.3 は AAA のため配慮として） |
| 通知 | オフラインの切り替え・さいころの結果・クーポン獲得は `aria-live="polite"`（4.1.3） |
| 地図 | 一覧で同じ内容、拡大・縮小は 44px のボタン、選んだスポットへ地図が動く（2.5.7） |
| 言語 | `<html lang>` を ja/en で切り替える（3.1.1） |
| 自動検査 | axe-core・pa11y は許可外のライセンスのため入れない。E2E で幅・44px・横スクロール・lang を数え、手動でキーボード・拡大・コントラスト計算・ナレーターを行う |

## 9. 性能・軽さ【仮定】
- 依存はルールの固定技術だけ（React・Leaflet・Express・zod・better-sqlite3）。CSV パーサ・Helmet・ルーターは入れない。
- CSV 取込は起動時（listen 前）に済ませ、リクエスト中に重い処理をしない（SEC-NODE-11）。取込の時間をログに出す。

## 10. 適用しないもの（理由）
| 項目 | 理由 |
|------|------|
| TLS・HSTS | localhost の HTTP のみ（競技の制約・ユーザー指定）。SEC-NODE-03 |
| ログイン・Cookie・CSRF トークン | ログインなし（competition ルール）。代わりに §4 |
| Node の Permission Model | better-sqlite3 はネイティブアドオンで `--allow-addons` が要り、今回は使わない（SEC-NODE-10、Could） |
| Trusted Types | Could（R-061） |
