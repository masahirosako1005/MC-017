## 3. 決めたこと【仮定】
- 応援のセリフは目で3通りを替える（「いい感じだね！」「その調子！」「どんどん進もう！」）。🎁かゴールまで3マス以内なら「あと n マスだよ！」、スポット・季節のマスは「『スポット名』、今度行ってみようよ！」。アバターごとの話し方の辞書（語尾）は U-07 で足す。
- 増えたきっかけの帯は、増やした画面から すごろくへ移ったときだけ出す（下のメニューから開いたときは出さない）。
- 転がる音は 0.3 秒ごとの「カチ」（動きを減らす設定では 0.25 秒ごと、0.5 秒で止まる）。

## 4. 誤りと直し
- T-025 で、開いたときに駒の位置へスクロールしていなかった（アプリの不具合）。画面の枠の「上へ戻す」が、子の盤のスクロールの後に走って打ち消していた。layout effect にして先に走らせた。
- T-025 の盤の形の確かめで、自動スクロール中に1マスずつ位置を読んで値がずれた（試験の書き方の誤り）。盤の中の位置（offsetTop・offsetLeft）を一度に読むよう直した（確かめる内容は同じ）。
- T-029 の単体試験でクライアントの `sfx.ts` を読み込んだため、DOM の型を持たないサーバー用の tsconfig で型検査が失敗した（15:42）。クライアントのコードを試す単体試験を `tests/unit/client/` に分け、クライアントの tsconfig（DOM あり）で検査し、サーバー用からは除いた。
- U-01 の E2E はさいころを `.dice` で探していた。立体のさいころは `.dice`（平らな目の CSS）を使わないため `data-testid="dice"` で探すよう直した（確かめる内容は同じ）。
