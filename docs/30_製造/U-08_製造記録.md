## 3. 決めたこと【仮定】
- T-043 は、主要8画面の h1・h2・下のメニュー・見えているボタンの文字に、かな・漢字が残らないことで確かめる（「日本語」のボタンは除く）。
- T-044 は、文字「大」（`html` の font-size 20px）で横スクロールが無いことと、下の主ボタンが画面内にあり押せることで確かめる。
- T-063 は、Tab を最大60回押して下のメニューの「遊ぶ」へ届くこと、フォーカスの枠が 3px の実線であることで確かめる。

## 4. 誤りと直し
- T-044: 文字の大きさは `html` の font-size で付けているのに、試験で `data-size` 属性を待っていた。font-size の 20px を確かめる形に直した。
- 通しデモ: 2回目の `scanAt` で、スポットの画面が前の「一覧」の表示を覚えているのに「一覧で見る」を押して地図に戻していた。一覧が出ていないときだけ押す形にした。
- 通しデモ: 「答え合わせを待っています」が出ず、アプリの条件の誤りが分かった（U-07 §4 で直した）。
- T-063: フォーカスの判定が要素の中の文字だけを見ていたので、ボタンそのものかを確かめる形にした。
