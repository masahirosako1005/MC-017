# コンセプト — 名古屋すごろく旅（仮称）

作成: 2026-11-09 14:02（実測） / 到達点: M3（1.1 続き） / 出典: `方向性.md` §1〜§18、`補強案.md` 案B（2026-11-09 12:37 人の判断）、`ペルソナ.md`、`データ調査.md` §2。資料にない事柄は【仮定】。

## 1枚でいうと

> **旅の続きが「盤の途中」と「相棒の予言」として手元に残り、次に来た日に答え合わせと続きができる。**
> 来るたびに駒が進み、相棒（アバター）が自分を分かってくる。だから、また来る。

## 再訪の因果（体験 → 気持ち → 次に来る理由）

```
 [今日の旅]                         [帰ったあと]                    [次に来た日]
 行く（QR）・買う（レジ横QR）       盤の途中で駒が止まっている  ──▶  続きから振れる
 書く（ひとこと）・誘う（LINE見本） 「次は秋の夕方、○○が        再訪ボーナスのさいころ
   │  さいころが振れる               気に入るはず」の予言        予言の場所でQR → 答え合わせ（さいころ2回）
   ▼                                 次に来た日から使えるクーポン  クーポンが使えるようになる
 すごろくで駒が進む・🎁でクーポン      │                            │
   │                                 ▼                            ▼
   ▼                         「続きが気になる」              「当たった！相棒が賢くなった」
 「楽しい・得した」          「本当に当たるか確かめたい」     → 次の予言・2枚目の盤へ（ループ）
                             「クーポンを使いたい」
```

| 段 | 中身 | 仕組み（ID は要件定義） |
|----|------|------------------------|
| 体験 | 観光・買い物・ひとこと・誘いが、さいころ1回になる。サーバーが目を決め、縦長の盤（45マス）で駒が1マスずつ進む。🎁マスで架空の店のクーポン | すごろく・きっかけ（R-013〜R-015・R-017〜R-019） |
| 気持ち | 「続きが気になる」（盤の途中で終わる）、「当たるか確かめたい・相棒を育てたい」（予言）、「使いたい」（次回から使えるクーポン） | 途中再開・予言・C5 クーポン（R-021・R-030〜R-033・R-026） |
| 次に来る理由 | 7日以上あけて来た日は**再訪ボーナス**。予言の場所で QR を読むと**答え合わせ**（さいころ2回）。ゴール後は**2枚目**（🎁が増え、マスの中身が変わる）。2枚目の後も**次の予言**が出続ける | 再訪の判定 C1・答え合わせ・2枚目 C8（R-005・R-031・R-020） |

## 既存のスタンプラリーとの違い（焼き直しにしない）

| 既存 | このアプリ |
|------|-----------|
| スタンプを集めると景品（1回の旅で完結） | スタンプは「さいころの回数」に変わるだけ。目的は盤の続きと予言の答え合わせ（旅をまたぐ） |
| 2周目は同じ7か所をもう一度 | 2枚目は🎁が10→15マスに増え、季節のマスが入る別の盤。2枚目の後は予言が次の行き先を出す |
| 満足しても再訪しない（満足度と2周目に関係なし、`データ調査.md` §2.4） | 「次に来る理由」を、帰る時点で手元に残す（盤の途中・予言・次回クーポン） |

## LLM を呼ばない「AI らしさ」

- 予言は、自分の行動（行ったスポットのタグ・時間帯）と、CSV 由来のダミー行動データ（同じ年齢層・同じ一緒に来た人の行き先）と、条件（段差少なめ・未訪問・次の季節）から、**決まった計算**で点数を出す。理由を3つまで見せる（`補強案.md` 案B）。
- 同じ入力なら同じ結果。外部 API・LLM は使わない（competition ルール）。画面では「AI」と言い切らず「あなたの旅と、みんなの旅から考えたよ」と書く。

## だれに効くか（ペルソナ）

| ペルソナ | 主に効く仕組み |
|----------|----------------|
| P-01 家族 | 子どもがさいころを振りたがる。次回クーポンと予言で「次の休み」に理由が残る |
| P-02 大学生 | 友達を誘う → 一緒に来る。立体のさいころ・縦長の盤で見た目が新しい |
| P-03 高齢夫婦 | 文字の大きさ・読み上げ（VOICEVOX か端末の声）・段差少なめの予言 |
| P-04 車いす | 「段差少なめ」を選ぶと、予言とコースから段差の多い所を外す。地図と同じ内容を一覧でも見られる |
| P-05 外国人 | 英語表示。次に来日したとき予言の答え合わせ |
| P-06 子ども | アバター4体（絵と声）・すごろく。予言カードを親に見せる |
| P-07 常連 | 週1回の再訪ボーナス・2枚目・予言が毎回新しい場所を出す |

## 守ること（制約）

- localhost のみ・ネットなしで全機能が動く。外部へ送るのは地図のタイルを読む時だけ（地理院の淡色地図、「出典：地理院タイル」を常時表示）。ネットが無い時は同じアイコンの簡易地図と「オフライン表示中」。
- ログインなし・ダミー ID・個人情報なし。LINE は見本（送らない）。声は同じ PC の VOICEVOX か端末内の読み上げで、どちらも無ければ文字だけ（R-041）。
- 【仮定】名称は仮称「名古屋すごろく旅」。スポットの内容とイベントは架空（一部の施設は位置のみ実在）。
