SC-02 アバター選択（画面モック）

index.html に無い画面。ホームの「変更」から開き、相棒を選ぶとホームに戻る。4枚の絵がそろった体だけ選べる（いまは4体とも選べる）。既定はともにゃん。

設計: docs/20_設計/画面設計/SC-02_アバター選択.md

相棒をえらぶ

いっしょに旅する相棒を選んでね。選ぶとホームにもどります。

絵はこのアプリのために作ったものです。声は設定で変えられます。

準備中の体（4枚そろわないとき）

  • happy の絵を CSS の filter: brightness(0) と薄い不透明度でシルエットにする（絵は別に作らない）。
  • 「準備中」と名前の文字を添える。押すと「準備中です。もうしばらく待ってね」。
  • いまは4体とも4枚そろっているので、この状態は出ない（見本）。

選んだ後

ほしろうが相棒になったよ

  • ホームへ戻り、ホームの絵・すごろくの駒・声がその相棒になる。
  • 送信中は「えらんでいます…」で、ほかのカードも押せない。
  • 失敗:「うまくいきませんでした。少し待ってから もう一度ためしてね。」と「もう一度」。
  • 読み込み中: 灰色の枠4つと「読み込み中…」。地図が無いので「オフライン表示中」は出さない。
