# ぴっこん制作メモ

## 作った内容
- 2026-11-09 14:31 のユーザー指示「形はペンギンぽくして色は水色にして。カメラを四角にして」で、茶色のスズメ型から**水色のペンギン型**に描き直した。設定の「お堀の小鳥」は変えていない。
- 頭を大きな丸、体を小さな卵形にした2等身。ペンギンと分かる手がかりは、左右に張った短いひれ・体の下の平たいオレンジの足・白いお腹・ハート形の白い顔・正面向きのオレンジのくちばし。頭のてっぺんの小さな羽は前の絵から残した（シルエットでだれか分かる手がかり）。
- 首から**四角いオレンジのカメラ**を下げた。角を少し丸めた横長の本体に、上のファインダーの出っ張りと丸いレンズを付けた。ストラップは顔の下からカメラの上の角へつないだ。
- `happy` はひれを下げた穏やかな顔、`excited` はひれを高く上げ、目と目のハイライトを大きくし、頭の左右にオレンジの光（十字）を足した。
- talk 版は、対応する通常版から口（くちばし）だけを変えた。閉じた口は横長の1枚のくちばし、開いた口は上下のくちばしの間に濃い色の口の中が見える形。
- 足元は `y=112`（足の楕円の下端）。背景は透明。

## 色数
- 固有色は5色: 線と目の濃い紺 `#2F4A5C`、体の水色 `#8DD3F0`、陰の水色 `#62B6DD`、お腹と顔の白 `#F3FBFE`、くちばし・足・カメラ・光のオレンジ `#F4A63A`。
- 共通の例外色として、目とレンズのハイライトに白 `#FFFFFF`、頬に薄いピンク `#F3B7B0` を使った（前の絵と同じ扱い）。
- 陰は頭と体の右側と右のひれの1段だけにした。

## 似たキャラクターの確認
- 水色・青のペンギンで有名なキャラクターとして、ポケットモンスターのポッチャマ、サンリオのタキシードサム、JR東日本の Suica のペンギン、ピングーを思い浮かべ、輪郭・配色・持ち物の組み合わせを比べた。画像の収集や模写はしていない。
- ポッチャマに多い「濃い青の頭と水色の体の塗り分け・顔の白い丸い模様・王冠のようなくちばし」、タキシードサムの「水兵帽と蝶ネクタイ」、Suica のペンギンの「濃い色の背中」、ピングーの「黒と白」は使っていない。全身同じ水色、ハート形の白い顔、ピンクの頬、頭の小さな羽、首から下げた四角いオレンジのカメラの組み合わせで区別した。
- 名古屋や城の地域キャラクターに多い、しゃちほこ・兜・城そのものの輪郭は使っていない。実在の人物・ロゴも参照していない。

## 表示確認と修正
- `プレビュー.html` を `127.0.0.1:8017` の一時サーバー（Node、リポジトリ外の一時スクリプト）から配信し、160px と 56px の両方をブラウザで確認した。確認後にサーバーを止め、一時スクリプトを消し、8017 が空いていることを確かめた。
- 初回確認: 160px ではペンギンの形・水色・四角いカメラ・ひれの上げ下げがはっきり読めた。56px でも happy / excited と通常 / talk の差は読めたが、talk の開いた口が濃い色の雫に見え、くちばしが開いているように見えなかった。
- 修正1: talk 2枚の口の下にオレンジの下くちばしを足した。再確認すると、下くちばしが小さすぎて線に埋もれ、まだ雫に見えた。
- 修正2: talk 2枚の上下のくちばしを大きくし、間の濃い色を口の中のすき間として見える大きさにした。160px・56px で再確認し、上下に開いたくちばしとして読めた。
- 最終確認: 56px でも目・くちばし・カメラがつぶれず、happy / excited はひれの位置と頭の横の光、通常 / talk はくちばしの開閉で判別できた。4枚の位置と絵柄もそろっている。
- 4枚が XML として読み込めること、`viewBox` が `0 0 120 120` であること、禁止された要素・属性（`script`・`text`・`image`・`filter`・`style`・`use`・`id`・`href`・イベント属性）がないこと、使った色、通常版と talk 版の違いが口の要素だけであることを PowerShell で確認した。
