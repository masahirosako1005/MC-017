# 外部リソース

アプリが使う、またはこの開発で使うOSS・外部データの一覧。**追加は `npm view` で実ライセンスを確認し、この表に書いてから `npm install`**。
許可ライセンス: MIT / BSD / Apache / ISC のみ。

## 1. 確認手順
```powershell
npm view <パッケージ名> name version license
```
- 実在しない（404）・許可外のライセンス・`UNLICENSED`/`SEE LICENSE IN` は導入しない。
- 推移依存（依存の依存）は M5 の提出前チェックで `node_modules` を走査して確認する（`/check` B-11）。

### 1.1 導入の前提（`.cursor/rules/environment.mdc`）
- リポジトリ直下の `.npmrc` に `ignore-scripts=true`（作成済み 2026-11-09）。`npm install` の前に必ず確認する。
- TypeScript は 6.0 系。`typescript-eslint` の peer は `typescript >=4.8.4 <6.1.0`（`npm view typescript-eslint peerDependencies.typescript`、確認 2026-11-09）で、6.0 系と整合。`vitest`・`vite`・`@vitejs/plugin-react`・`tsx`・`@playwright/test` は typescript の peer 指定なし。
- `ignore-scripts=true` の影響: `esbuild`（`tsx` の依存）は `install` スクリプト（`node install.js`）を持つが、バイナリは別パッケージで供給される想定【仮定・未検証】。`better-sqlite3` 13.0.3 は registry 上の `scripts` に `install` がなく、`dependencies` は `node-addon-api` のみ（取得物 27MB でネイティブ同梱の可能性。**未検証**）。導入後に `node -e` で SQLite が開けることを確認し、結果をここに書く。
