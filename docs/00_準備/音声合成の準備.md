### 3.4 計測方法
- 文: 「また来てね。次は春の桜を見に行こう。」（18文字）
- 手順: 話者ごとに `POST /audio_query?speaker=<id>&text=<文>` → 返った JSON をそのまま `POST /synthesis?speaker=<id>` に送る。これを話者ごとに4回、8 → 70 → 54 → 42 の順に直列で実行した。
- 時間: PowerShell の `Stopwatch` で、`audio_query` と `synthesis` のそれぞれの応答までを測った（同じ PC 上の HTTP を含む）。
- 音声長: WAV のデータ部のバイト数 ÷ 毎秒バイト数（ヘッダから読んだ値）。
- 保存先: `C:\voicevox-work\samples\speaker<id>_run<n>.wav`（16ファイル）。
- エンジンは起動時に全モデルを読み込まない設定（`--load_all_models` なし）なので、**各話者の1回目はモデルの読み込みを含む**。
